# Agentic State

This directory is the durable project ledger for the Orchestrator.

## State files

- `state/project-state.md`: global project status, requirements, architecture, baseline, advanced work, risks, and checkpoints.
- `state/dependency-graph.md`: problem-oriented work items, dependencies, and statuses.
- `state/decisions.md`: immutable human decision history.
- `state/progress.md`: observed actions, outputs, failures, retries, and verification.
- `state/active-task.md`: current local task and next action.

## Templates

Use templates for decomposition, handoffs, decisions, experiments, changelog entries, evidence, and trajectories. Keep examples clearly separate from actual records. Evidence must reference real tool output.

## Checkpoints

Track: Requirements Approved, Architecture Approved, Baseline Strategy Approved, Baseline Verified, Advanced Strategy Proposed, Advanced Strategy Approved, Advanced Solution Verified, and Submission Ready.
